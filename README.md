# Маслов — сайт продавца моторных масел

Демо-проект для портфолио: лендинг с каталогом для продавца оригинальных моторных масел.

**Сайт:** https://ambosius.github.io/maslov/

## Что внутри

- Первый экран с видео: бесшовный цикл, склеенный через ffmpeg (конец растворяется в начало)
- Блок «Почему ко мне, а не на маркетплейс»: подбор по VIN, бесплатная замена, выравнивание цены
- Каталог-прайс с фильтрами по вязкости и бренду
- Заявка: позиции из каталога попадают в форму сами, маска телефона
- Карта Яндекса в тёмной теме с адресом и маршрутом
- Админка продавца (`admin.html`): цены, наличие, товары, заявки — на Supabase с защитой через RLS

Как подключить базу — в [SETUP.md](SETUP.md).

## Стек

Чистые HTML, CSS и JavaScript — без фреймворков и сборщиков. База — Supabase (PostgreSQL), запросы обычным `fetch`, без SDK.
