# Маслов — сайт продавца моторных масел

Демо-проект для портфолио: лендинг с каталогом для продавца оригинальных моторных масел.

**Сайт:** https://ambosius.github.io/maslov/

## Что внутри

- Первый экран с видео: бесшовный цикл, склеенный через ffmpeg (конец растворяется в начало)
- Подбор масла по автомобилю: марка → модель → двигатель, вязкость, допуск, объём заливки
- Каталог-прайс с фильтрами по вязкости и бренду
- Заявка: позиции из каталога и машина из подбора попадают в форму сами, маска телефона

## Стек

Чистые HTML, CSS и JavaScript — без фреймворков и сборщиков.
